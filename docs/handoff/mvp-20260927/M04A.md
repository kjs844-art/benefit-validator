## 검증

read-only 코드/데이터 흐름 검토, 관련 파일·정확한 SHA·증거 한계 기록. 허용된 로컬 합성 테스트가 필요하면 격리 환경에서만 수행하고 외부 호출은 차단한다. HTTP 공격/자동 스캔/실메일 조회는 이 업무 범위 밖.

단일 테스트 통과는 기능 전체 통과가 아니다. 검사에는 명령, exit code, 대상 SHA,
데이터 범위와 실행 환경을 함께 기록한다. 테스트용 비밀 문자열도 명백한 합성값만 사용한다.
