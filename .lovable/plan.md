# Google Gmail 연결 차단 해소

## 구현
- 공개 개인정보처리방침과 서비스 이용약관 페이지를 추가합니다.
- 첫 화면에서 두 문서로 이동할 수 있게 연결합니다.
- Google 인증 플랫폼에 입력할 배포 주소와 문서 주소를 정리합니다.
- 화면과 주소를 확인한 뒤 현재 공개 사이트를 업데이트합니다.

## Google 쪽 최종 작업
- 사용자가 Google 인증 플랫폼에서 앱 홈페이지·개인정보처리방침·서비스 약관 URL을 저장합니다.
- Audience에서 앱을 프로덕션으로 전환합니다.
- Gmail 읽기 전용 권한은 Google의 민감한 권한이므로, 일반 공개에는 별도의 Google 검증 심사가 필요할 수 있습니다.
