# Claude 디자인 변경 검토 반영

## 목표
Claude가 만든 디자인 시스템과 화면 개선을 가져오되, 최근 확정한 방향인 “설명보다 제품 자체를 보여주는 화면”을 유지합니다. 기능·데이터 정확성·Gmail 흐름은 바꾸지 않습니다.

## 작업 범위
1. GitHub PR #1의 변경을 현재 프로젝트에 반영합니다.
2. 첫 화면은 PR의 긴 소개·원칙·가능/불가능 설명 섹션을 제거하고, 짧은 제목·주요 버튼·실제 데모 화면만 남깁니다.
3. 새 디자인의 공용 요소, 좌측 메뉴, 혜택 명세서형 카드, 한국어 조판, 단일 강조색 체계는 유지합니다.
4. 브랜드 마크를 파비콘으로 만들어 기존 아이콘을 교체합니다.
5. MCP 동의 화면과 Gmail 연결 완료 화면의 여백과 위계를 새 디자인에 맞춥니다.
6. 버튼·입력·선택 상자를 새 디자인에 맞게 정리하고, 혜택 입력 화면은 기능을 건드리지 않은 채 세 구역으로 나눕니다.
7. 공유 이미지는 1200×630 전용 이미지로 준비합니다. 공개 주소가 생긴 뒤 넣어야 하는 절대 이미지 주소는 첫 배포 단계에서 연결합니다.
8. Claude용 스킬 복사는 하지 않습니다. Lovable과 Claude가 서로 다른 활성화 방식을 사용하기 때문입니다.

## 검증
- 타입 검사와 빌드를 실행합니다.
- 비로그인 첫 화면과 데모를 데스크톱·모바일에서 확인합니다.
- 로그인 화면, 잘못된 주소, Gmail 복귀 화면을 확인합니다.
- 가능한 경우 로그인 후 화면에서 긴 서비스명, 0·모름 표시, 입력·수정 흐름을 확인합니다.
- 실행하지 못한 검사는 통과로 보고하지 않고 남은 제한으로 구분합니다.

## 배포
이번 작업에서는 공개 배포하지 않습니다. 검증 결과를 확인받은 뒤 별도 승인으로 배포합니다.
